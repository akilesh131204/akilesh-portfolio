# Akilesh M - Developer Portfolio

Personal portfolio of Akilesh M, a Full Stack (MERN) developer from Coimbatore, Tamil Nadu.

**Live site:** https://akilesh-portfolio.netlify.app

## Sections
- About, Skills, Projects, Experience, Education and Certifications, Contact
- Projects: Eventify (MERN event platform), AI-assisted cheating detection for virtual interviews, IoT capacity level and leakage detection
- Internship and course certificates open in an on-page viewer, with an online verification link where available
- Contact form delivered to my inbox through Formspree
- Responsive layout for mobile, tablet and desktop

## Tech stack
React, Vite, Tailwind CSS, Lucide icons. Deployed on Netlify.

## Run locally
```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Editing content
All text, links and certificates are configured in `src/data.js`. Certificate images are in `public/certificates`.
