# Akilesh M - Developer Portfolio

Portfolio of Akilesh M, a Full Stack (MERN) developer from Coimbatore, Tamil Nadu.

**Live site:** https://akilesh-portfolio.netlify.app

## Sections
- **About Me** with profile photo and quick facts
- **Resume** - in-page PDF preview with download
- **Skills** - technical and soft skills
- **Projects** - Eventify (MERN capstone, deployed), AI-assisted cheating detection, IoT gas leakage monitor, with frontend and backend source links
- **Experience and Education** - internships with certificates
- **Certifications** - viewable certificates with verification links
- **Contact** - form delivered to my inbox, plus LinkedIn, GitHub and email

## Highlights
Responsive layout, scroll animations, project filters, certificate viewer and an accessible contact form.

## Tech stack
React, Vite, Tailwind CSS, Lucide icons. Deployed on Netlify.

## Run locally
```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Editing content
All text, links, projects and certificates are in `src/data.js`. Certificate images are in `public/certificates`.
